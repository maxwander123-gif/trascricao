CONEXÃO COM A OPENAI

Uma chave. Tudo conectado.

Essa configuração é feita uma vez, no seu computador.

  1. Crie uma chave em OpenAI → API keys ↗, em uma conta com créditos disponíveis para a API.
  2. Na pasta do aplicativo, abra o arquivo .env e preencha OPENAI_API_KEY=sua_chave.
  3. Salve o arquivo e clique em “Verificar conexão”.

A chave fica no servidor. Os áudios e textos são enviados à OpenAI para processamento. A cobrança da API é separada da assinatura do ChatGPT.
